# Assets

Place the following image files here:

- `icon.png` - App icon (1024x1024px)
- `adaptive-icon.png` - Android adaptive icon foreground (1024x1024px)
- `splash.png` - Splash screen image (1284x2778px recommended)

You can generate these using tools like:
- https://easyappicon.com
- https://appicon.co
- Figma with proper export settings
